5. THE CLEAN-vs-DEGRADED GAP: an open unknown, not a number
============================================================================
  MEASURED: fla on one T4, in the configuration this session observed
  the T4's 65536 B of optin shared memory and its sm_75
  compute capability force on it.  That is all.

  NOT MEASURED, and not estimated anywhere in this file: what the same
  code does on a card with >= 166,912 B optin shared memory AND cc major
  >= 8.  Scaling this number by a stage ratio, a tile ratio or a
  precision ratio would be inventing a measurement.

  The four gap classes this project uses (notes/19 section 6):
    (i)   the DSL cannot express it
    (ii)  the DSL can express it and does not find it
    (iii) not yet implemented on the DSL side
    (iv)  does not exist for this arch

  REACHABLE by this measurement:
    (ii)  If a port lands close to fla-on-T4, the residual is a
          scheduling question and this run can address it, because both
          sides are on the same silicon with the same numerics and the
          same degraded reference configuration.
    (i)   Reachable only negatively: a port that lands orders of
          magnitude off cannot be separated into (i) vs (ii) by a
          timing alone.  The three-port ladder is the instrument for
          that, and it is reported above.
    (iii) The ladder across the three ports measures exactly this, if
          all three are present.

  STRUCTURALLY UNREACHABLE by this measurement, at any run quality:
    (iv)  Fixed by the silicon.  There is no bf16 MMA below sm_80 and
          IS_TF32_SUPPORTED is False, so fla's tl.dot cannot reach a
          tensor core on this card however long the run takes.  A gap
          that is really 'fla emits HMMA and TinyGrad emits FFMA' is
          (iv) here -- and is untouched by every number above, because
          the HMMA never executes on this device.
    ALSO UNREACHABLE: fla-in-its-worst-config versus fla-in-its-best.
          That needs the card this study does not have.  It stays open.
